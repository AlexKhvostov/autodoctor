# Как подключить AI-чат (Filament + Laravel + Abacus)

Порядок для менеджера. После шагов можно переписываться с чатом в приложении **без** `dart-define` на клиенте.

## 1. Ключ провайдера (Abacus)

1. Войдите в https://abacus.ai / ChatLLM.
2. Слева внизу откройте **RouteLLM API**.
3. Создайте API key.
4. Положите ключ **только** в серверный `.env` (не в git, не в Filament UI):

```env
AI_ABACUS_API_KEY=ваш_ключ
AI_ABACUS_BASE_URL=https://routellm.abacus.ai
AI_ABACUS_MODEL=route-llm
```

Опционально fallback DeepSeek:

```env
AI_DEEPSEEK_API_KEY=
AI_DEEPSEEK_BASE_URL=https://api.deepseek.com
AI_DEEPSEEK_MODEL=deepseek-chat
```

Если ключ уже светился в чате/почте — **перевыпустите** его в Abacus.

На Windows PHP часто нет CA-сертификатов. В проекте уже лежит `apps/api/storage/certs/cacert.pem` — Laravel использует его для HTTPS к Abacus автоматически.

## 2. Админ-пользователь и миграции

Из папки `apps/api`:

```powershell
php artisan migrate
php artisan db:seed --class=AiConfigSeeder
php artisan db:seed
```

Логин админки по умолчанию после полного seed:

- URL: `http://localhost:8000/admin`
- Email: `admin@autodoctor.local`
- Password: `password`

Смените пароль после первого входа.

## 3. Что править в Filament (`/admin`)

Группа **AI**:

1. **Prompt versions** — текст системного промпта; действие **Approve**.
2. **AI configs** — primary/fallback provider + model, выбор утверждённого prompt, enable/active.
3. **Test connection** — проверка ключа без пользовательских диалогов.
4. **Activate** — сделать конфиг активным (его использует мобильное приложение).

Секреты в UI **не** редактируются: только статус «ключ задан / не задан» из `.env`.

Канонический текст промпта также лежит в [`prompts/ai-chat-system.md`](ai-chat-system.md) — правки для продакшена делайте через Filament (или обновите сидер и перезалейте approved-версию).

## 4. Мобильное приложение

Обычный запуск API + приложения (без `DEEPSEEK_API_KEY`):

```powershell
# терминал 1
cd apps/api
php artisan serve

# терминал 2
cd apps/mobile
puro flutter run
```

Вкладка **AI** → **Новый чат** → сообщение. Ответ идёт через Laravel → Abacus.

## 5. Что нужно от вас (чек-лист)

| # | Что | Куда |
|---|-----|------|
| 1 | API-ключ Abacus | `apps/api/.env` → `AI_ABACUS_API_KEY` |
| 2 | (опц.) DeepSeek fallback | `AI_DEEPSEEK_API_KEY` |
| 3 | Вход в `/admin` | смена промпта / модели без новой сборки APK |
| 4 | Правки промпта | Filament → Prompt versions → Approve |

## 6. Поведение чата (v8+)

- **Этапы:** 1-е сообщение пользователя — уточнения/проверки; 2-е — локализация вариантов + мягкий офер помощи со СТО; далее — суженный разбор и при необходимости текст обращения к СТО.
- **Заметки:** после ответа сервер может сохранить устойчивые факты в две полки:
  - о машине (`vehicle_ai_notes`) — например «кабриолет»;
  - о пользователе (`guest_profile_ai_notes`) — имя, «вы/ты», стиль общения.
  Заметки о пользователе живут на **гостевом профиле** устройства (не только в сессии ~30 дней): при обновлении сессии приложение передаёт тот же `guest_profile_id`. Симптомы текущей жалобы туда не пишутся. Если пользователь просит иначе — заметка перезаписывается (старое убирается).
- **Диалоги** сохраняются на сервере (`assistant_threads` / `assistant_messages`). В админке: `/admin` → AI → **Dialogues**.
- Пользователю это обычно незаметно: отдельного UI для заметок в MVP нет.

## 8. Безопасность

- Ключ LLM только на сервере.
- Мобилка не знает провайдера и не хранит API-токен LLM.
- Смена модели/промпта в админке применяется к следующему сообщению без пересборки клиента.

## 9. Админка: пользователи

`/admin` → **Пользователи → Пользователи приложения**

- Список: имя/email (или гость), тип, счётчики сессий/машин/заметок/диалогов.
- Карточка: сводка + вкладки **Сессии**, **Заметки о пользователе**, **Машины и заметки по ним**, **Диалоги** (с переходом в переписку).
- Из диалога можно кликнуть на аккаунт и попасть на карточку пользователя.
- Отдельного device-id в MVP нет — якорь: **Guest profile ID** (+ email после входа).
- AI-заметки и тексты чата очищаются от битой UTF-8 при сохранении/загрузке (иначе админка падала на JSON).
