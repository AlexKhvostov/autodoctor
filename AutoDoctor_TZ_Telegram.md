# AutoDoctor — ТЗ пилота в Telegram

**Версия:** 0.5  
**Дата:** 2 сентября 2026  
**Статус:** рабочий черновик (согласованные решения ниже)  
**Канал:** Telegram-бот (основной продукт) + Mini App (вторично)  
**Backend:** тот же Laravel Cloud (`apps/api`)  
**Android/iOS:** на паузе, `apps/mobile` не удаляем  

Канон этого пилота — этот файл. Старое [`AutoDoctor_TZ_MVP.md`](AutoDoctor_TZ_MVP.md) — архив нативного приложения.

---

## 1. Зачем пилот

Гипотеза:

> Владелец готов вести историю авто **в переписке**, если не надо заполнять сложные формы.

Смысл продукта прежний: собрать факты по машине и помочь с обслуживанием. Канал другой: человек пишет боту как знакомому механику-секретарю. Mini App — посмотреть и поправить, не «вести учёт».

Новый репозиторий не нужен. Бот — ещё один клиент того же API.

## 2. Принципы (не нарушать)

1. **Нет обязательных анкет.** Чеклист полей тот же, что у старых форм (карточка авто, мастер истории, запись ТО). Собирает его бот разговором.
2. **Регистрация = Telegram.** Кто написал боту, тот пользователь (`telegram_id`). Логин-пароль и Google в пилоте не используем.
3. **Первый диалог — машина.** `/start` → «расскажите про авто» → уточнения → выжимка → кнопка **Записать**.
4. **Работы — тот же ритуал.** Свободный текст («сегодня заменил шины») → дыры → выжимка → **Записать**.
5. **Тихо** пишем только лёгкий профиль человека (как обращаться, «говорите проще»). Не заводим так машину и не пишем журнал ТО.
6. **«Не знаю» — сохранённый отказ помнить.** Пока человек сам не вспомнит, это поле больше не спрашиваем.
7. **Сервер знает дыры**, не «память чата». В промпт: что заполнено / пусто / unknown.
8. **1–3 уточнения** за ход, не допрос. Можно сохранить неполную работу (с «не знаю» в выжимке).
9. **Ничего не выдумываем** (пробег, дата, марка шин).
10. **Один бот, один чат.** Темы — наше меню, не обязательные вкладки Telegram.
11. **Mini App позже и меньше.** Android не развиваем в этом пилоте.
12. **Токены AI** — учёт ответов модели (не «топливо» из старого Android-UI). Пока токены бесплатны для пользователя, платит продукт — поэтому пилот **только по белому списку**.

## 3. Границы пилота

| Входит | Не входит |
|--------|-----------|
| Бот + вебхук на текущем Laravel Cloud | Отдельный сервер / репозиторий бота |
| Вход через Telegram | Google / Apple / пароль как основной вход |
| 1 автомобиль | Второе авто, семейный доступ |
| Первый диалог: завести авто | Обязательная веб-форма гаража |
| Журнал работ из чата с кнопкой «Записать» | Мастер истории на 20 экранов |
| Меню: Темы, Новая тема, Что записано | Native topics Telegram как зависимость |
| Чеклист слотов из каталога ТО | Новый каталог «с нуля» |
| Тот же AI, админка `/admin` | Полный UI Flutter |
| Белый список Telegram ID до любой модели | Открытый бот «для всех» на бесплатных токенах |
| Списание **токенов** за ответы AI | Слово «топливо» в продукте бота |
| Заложить Stars / пакеты токенов в продукт | Магазин приложений, подписка App Store |

## 4. Сценарии

### 4.0. Белый список (обязателен, пока токены за наш счёт)

Пока пользователь не платит, **любой** `/start` с улицы жжёт деньги на LLM. Поэтому:

- допуск только `telegram_user_id` из белого списка (env Cloud `TELEGRAM_ALLOWLIST_IDS` и/или таблица в админке);
- не в списке: **никакого** вызова модели, шаблон: «AutoDoctor сейчас в закрытом пилоте. Если ждали доступ — напишите нам.»;
- пустой список = никто не проходит (безопасный дефолт), не «все можно»;
- проверка **до** сессии AI и до списания токенов;
- свой ID смотрит у @userinfobot или в логе апдейта; админ добавляет в список без релиза приложения.

Снятие списка — отдельное решение, когда включена оплата пакетов токенов.

### 4.1. Регистрация

Отдельного экрана регистрации нет. Первое сообщение боту (только если ID в белом списке):

- создаём (или находим) профиль по `telegram_id`;
- подтягиваем имя из Telegram, если есть (тихо в профиль, можно поправить «зовите …»);
- выдаём стартовый пакет **токенов** (демо), как новым гостям в API;
- сразу сценарий 4.2.

Согласия: коротко в `/start` (обязательная обработка данных для ведения журнала). Без отдельного квеста из Android.

### 4.2. Первый диалог — завести авто

1. Бот: кто такой AutoDoctor (2–3 предложения).  
2. «Расскажите про машину — что помните: марка, год, пробег.»  
3. Человек свободным текстом.  
4. Бот сверяет чеклист 5.1, спрашивает только открытые слоты (кнопки: бензин/дизель, «не знаю»).  
5. Выжимка, например: *Volkswagen Polo, 2014, бензин, пробег 148 000, VIN не знаем.*  
6. Кнопка **Записать**.  
7. Нажал — машина в записях пользователя, можно писать про работы.  
8. «Не то, это Golf» — человек пишет; новая выжимка; снова **Записать**.  
9. Пока не нажали — в БД машины нет. Болтать можно; журнал работ бот не пишет: «сначала закроем карточку авто».

VIN не блокер. «Не знаю VIN» сохраняется и больше не спрашивается, пока сам не пришлёт.

### 4.3. Запись работы

Нужна уже записанная машина.

1. «Сегодня заменил шины.»  
2. Бот смотрит каталог (шины), прошлые записи, открытые слоты.  
3. Уточнения: пробег? все 4 / ось? сезон? — только дыры, не «не знаю».  
4. Выжимка: *Замена шин, 2 сентября 2026, все 4, зима, 148 000 км.*  
5. **Записать**.  
6. Готово — строка в журнале / history, план может опереться позже.  
7. «Не зима, всесезонка» — правим черновик, снова кнопка. Без кнопки работы в журнале нет.

Если похоже на повтор («масло уже было на 80 тыс.»): один вопрос — это новая замена?

### 4.4. Темы

Синее меню бота и/или команды:

- **Темы** — список последних (до 10) кнопками; нажатие делает тему активной; бот: *Пишем в тему: скрип тормозов.*  
- **Новая тема** — новая `assistant_thread`, как «новый чат» в приложении.  
- **Что записано** — краткий дамп карточки и последних работ текстом (Mini App не обязателен в пилоте).

Пока тем нет — одна «диалог» (часто это как раз первое «про авто»).

Нативные вкладки Telegram не обязательны. Если включим позже — `thread_id` Telegram маппится на наши темы.

### 4.5. Mini App (не первый спринт)

Кнопка «Гараж»: карточка, пробег, список работ, остаток **токенов**, кнопка **Купить токены**. Сбор фактов всё равно в чате. Оплата пакетов — здесь же через счёт Telegram (раздел 10).

### 4.6. Нет токенов

Ответ AI не уходит, бот пишет, что токены кончились, кнопка **Купить токены**. Журнал уже записанных работ не пропадает. Уточнения «записать шины» тоже тратят AI, пока не сделаем дешёвые шаблонные вопросы без LLM (не обязательно в пилоте).

## 5. Чеклист данных (бывшая форма)

Источник слотов — каталог работ и API (`vehicles`, `history_answers`, журнал обслуживания), не выдумка модели.

### 5.1. Авто

| Слот | Обязателен для первой записи? |
|------|-------------------------------|
| Марка | желательно |
| Модель | желательно |
| Год | нет |
| Топливо / тип двигателя | если без этого нельзя выбрать правила |
| Текущий пробег | нет, но полезен |
| VIN | нет |

Первая запись авто — только после **Записать**. Потом «пробег уже 150» можно тихо дописать в карточку. Смена марки/модели — снова выжимка и кнопка.

### 5.2. Работа (журнал)

| Слот | Смысл |
|------|--------|
| Код работы + название | масло, шины, колодки… |
| Статус | сделал и помню / делал не помню когда / не делал / не про эту машину / не знаю |
| Дата | день или «сегодня» |
| Пробег на работе | км |
| Специфика | шины: ось/все 4, сезон; остальное — если человек сам сказал |
| Кто | сам / СТО — по желанию |

Уточняем только пустые слоты не в статусе «не знаю». Неполную строку можно вынести в выжимку.

### 5.3. «Не знаю»

Сказал «не помню пробег» / «хз когда»:

- в выжимке работы это видно; после **Записать** — `unknown` / `done_unknown` как сейчас в API;
- слот закрыт для вопросов;
- один раз: «вспомните — напишите»;
- снова спрашивать, только если сам поднял («кстати, на 140»).

Пустой слот ≠ «не знаю». Пустой можно спросить.

Для авто то же: «VIN не знаю» после записи карточки не долбить.

### 5.4. Сверка с прошлым

Перед вопросом:

- уже есть число/дата — не переспрашивать;
- новая фраза про ту же работу — уточнить, новый факт ли это;
- пробег события меньше прошлого — один мягкий вопрос;
- план «скоро масло», в журнале пусто и нет unknown — напомнить изредка, не каждым сообщением.

### 5.5. Куда писать

Всё в записи **этого** пользователя.

| Что | Как |
|-----|-----|
| Обращение, стиль, город | тихо, заметки профиля |
| Новая / другая машина | выжимка + **Записать** → `vehicles` |
| Мелкий пробег на уже той же машине | можно тихо |
| Что и когда сделали | выжимка + **Записать** → журнал / history |

Черновик живёт в активной теме, пока не записан или не брошен.

## 6. AI и сервер

AI: разобрать текст, сопоставить слоты, 1–3 вопроса по открытым дырам, сформулировать выжимку, ответить по фактам («когда масло?»).

Сервер: снимок слотов в промпт; после **Записать** — те же эндпоинты журнала/машины; темы = `assistant_threads`.

Кнопка **Записать** — не «модель решила сохранить», а явный callback: сервер пишет черновик в БД.

Не диагноз, не выдуманный регламент.

Списание **токенов**: ответ модели (и служебные вызовы памяти, как сейчас). Нажатие **Записать** без нового LLM — не должно снимать пакет «как за длинный ответ»; это фиксация уже согласованного черновика.

## 8. Меню бота (сводка)

- `/start` — первый диалог про авто, если машины нет; иначе короткое «чем помочь».  
- **Темы** / `/topics` — список, переключение.  
- **Новая тема** / `/new`.  
- **Что записано** / `/garage`.  
- **Токены** / `/tokens` — баланс и пакеты (сначала демо, потом Stars).

---

## 9. Критерии приёмки пилота

- `/start` без инструкции: рассказ про авто → выжимка → **Записать** → машина в профиле и в админке.  
- «Заменил шины» → уточнения → выжимка → **Записать** → строка журнала. Без кнопки журнала нет.  
- Правка текстом меняет выжимку, старая не пишется.  
- «Не помню пробег» + **Записать** → больше не спрашиваем пробег, пока сам не назовёт.  
- Темы переключаются с меню, контекст AI не смешивается.  
- Нет обязательной веб-формы на эти сценарии.  
- Не в белом списке — шаблон без LLM.  
- Кончились токены — понятное сообщение и путь к покупке (хотя бы демо-stub).  
- Бот не выдумывает цифры.

## 10. Монетизация и оплата токенов

В продукте бота валюта — **токены** (пакеты ответов AI). В коде API кошелёк ещё может называться `agent_fuel_*` / мл — это технический долг, **не показывать слово «топливо» пользователю бота**. Вторая валюта не нужна: один баланс, другие кнопки оплаты.

Пока токены бесплатны для пилота — **белый список** (раздел 4.0), не открытый бот.

### 10.1. Что продаём

Продаём **пакеты токенов / ответов AI**, не «право завести машину». Журнал и карточка авто — ценность, ради которой покупают диалог. Имеет смысл:

- бесплатно: завести авто, писать работы (минимум LLM или короткие шаблоны), смотреть «что записано»;  
- платно: свободный совет, разбор симптомов, длинный диалог.

Иначе человек не поймёт, за что списали, когда нажал «Записать».

Пакеты как сейчас в конфиге (ориентир прежних «мл») → «примерно N ответов». Подписка «безлимит в месяц» — не в первом пилоте.

### 10.2. Как взять деньги внутри Telegram

Токены — **цифровой товар**. Правила Telegram для виртуальных товаров в боте и Mini App: штатный путь — **Telegram Stars** (счёт `sendInvoice` / Mini App `openInvoice`, валюта `XTR`). Карта «мимо Telegram» за токены внутри бота часто противоречит их правилам.

Поток:

1. Мало токенов → «Купить токены».  
2. Пакеты кнопками (Stars).  
3. Пользователь платит в Telegram.  
4. Webhook `successful_payment` / `pre_checkout` → зачисление **токенов** на тот же кошелёк, не stub.  
5. Комиссия и вывод Stars — по кабинету BotFather / Telegram (закладывать в цену пакета).

Пользователь в Беларуси должен **уметь купить Stars** в клиенте Telegram. Если Stars в регионе недоступны — запасной контур не в чате: оплата на `autodoctor.by` (bePaid / карта / ЕРИП) и зачисление токенов на профиль, связанный с `telegram_id`. Это уже обычный интернет-эквайринг, юрлицо, оферта, чек — дольше, чем Stars.

YooKassa/Stripe **внутри бота за токены** — не основной план (и Stripe для BY обычно мёртв).

### 10.3. Что делать по этапам

| Этап | Оплата |
|------|--------|
| Закрытый пилот (белый список) | Демо-токены + stub покупки. Проверяем продукт, не кассу. |
| Открытый бот | Stars: 2–3 пакета. Юр. текст в боте (оферта, что это AI-пакет). |
| Если Stars мало кто может купить | Сайт + местный эквайринг, зачисление на тот же кошелёк. Mini App только показывает кнопку «оплатить на сайте» для этого контура. |

Вывод денег: Stars — через Telegram; сайт — на расчётный счёт ИП/ООО в РБ.

### 10.4. Чего не делать

- Не списывать большой пакет за одно «Записать».  
- Не держать отдельный «баланс Telegram» в обход существующего кошелька токенов (в коде может ещё называться `agent_fuel_wallets`).  
- Не обещать безлимит, пока не умеем считать себестоимость Abacus/DeepSeek.  
- Не включать боевые платежи, пока не закрыты оферта и тестовый платёж 1 Star.
