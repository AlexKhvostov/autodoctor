# План пилота Telegram (закрытый круг)

Канон продукта: [`AutoDoctor_TZ_Telegram.md`](../AutoDoctor_TZ_Telegram.md) **v0.5**.  
Android на паузе. Деньги на LLM платит продукт, пока пользователь не покупает пакеты — **сначала белый список**.

В речи продукта: **токены**. Не «топливо». В коде API кошелёк ещё может называться `agent_fuel_*` — не выносить это слово в бота.

---

## Зачем этапы такие

1. Без белого списка бот нельзя даже включать на публичном username: случайный `/start` = ваши токены.  
2. Без вебхука и личности Telegram нет журнала «кто это».  
3. Без кнопки **Записать** нельзя писать машину и работы в БД.  
4. Оплата Stars — после того, как закрытый круг прошёл сценарии, иначе касса мешает продукту.

---

## Этап 0 — защита бюджета (делать первым)

- Env Cloud: `TELEGRAM_ALLOWLIST_IDS` (список числовых `telegram_user_id`).  
- Пустой список = **никто** не проходит.  
- Не в списке: статичный отказ, **ноль** вызовов модели.  
- Логировать отказ (id, username) — чтобы добавить человека без поиска в чате.  
- По желанию: таблица в Filament, чтобы не деплоить env на каждую фамилию.  
- Тест: чужой id не тратит токены; свой id проходит дальше.

Критерий готовности: бота можно повесить на webhook, улица не жжёт Abacus/DeepSeek.

---

## Этап 1 — скелет бота

- Токен бота только в Cloud env.  
- `POST /telegram/webhook` в `apps/api`, секрет вебхука.  
- Профиль по `telegram_id` (без Google).  
- `/start`: согласие коротко + если нет машины — сценарий «расскажите про авто».  
- Локально: long polling. Пилот: HTTPS webhook на `https://api-dev.autodoctor.by`.

Критерий: вы в белом списке пишете боту, сообщение доходит до Laravel, в админке виден пользователь.

---

## Этап 2 — первое авто

По ТЗ §4.2: свободный текст → дыры чеклиста → выжимка → кнопка **Записать** → `vehicles`.  
Пока кнопки нет — машины в БД нет.

Критерий: карточка в профиле и в `/admin` после нажатия, не после болтовни.

---

## Этап 3 — работы в журнале

По ТЗ §4.3: «заменил шины» → слоты → выжимка → **Записать**.  
«Не знаю» закрывает слот. Сервер, не память чата, знает пусто / известно / unknown.

Критерий: без кнопки строки журнала нет; правка текстом меняет выжимку.

---

## Этап 4 — темы

Меню: **Темы**, **Новая тема**, **Что записано**.  
Темы = существующие `assistant_threads`, не обязательные native topics Telegram.

---

## Этап 5 — токены (учёт), не касса

- Списание за ответ модели. **Записать** без нового LLM — не как длинный ответ.  
- Команды `/tokens`: остаток, демо-зачисление.  
- Тексты бота: «токены», не «топливо» / «заправка».

---

## Этап 6 — позже: открытие и Stars

Снимать белый список **только** когда: пакеты продаются **или** сознательно принят риск открытого демо.  
Stars / сайт+эквайринг — по ТЗ §10, не в первом закрытом круге.

---

## Что не делать в этом плане

- Новый репозиторий бота.  
- Развивать Flutter как основной канал.  
- Путать fuel (старый Android) и токены бота в UX.  
- Вызывать LLM до проверки белого списка.
